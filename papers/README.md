# Papers

想法阶段的文献入口。当前目标是：根据当前空间状态与近期动作，估计持球者各个候选传球的预期价值。

四篇文献各管一件事。SoccerMap 负责从空间状态生成预测图，SPADL 是事件格式，VAEP 提供已发生动作的价值定义和基线，EPV 与 un-xPass 处理候选动作的成功概率和价值。需要单独研究的是动作结果预测，以及如何估计尚未执行的传球。

| 文献 | 在本题中的位置 | 笔记 |
| --- | --- | --- |
| VAEP | 用进球概率与失球概率的变化评价已发生动作，并提供 SPADL 事件格式 | [vaep.md](vaep.md) |
| SoccerMap | 用全卷积网络，从球员与球的空间状态生成全场预测图 | [soccermap.md](soccermap.md) |
| EPV | 把局面价值拆成动作选择、成功概率，以及成功或失败后的期望价值 | [epv.md](epv.md) |
| un-xPass | 在同一局面下比较实际传球与其他可能终点 | [un-xpass.md](un-xpass.md) |

第一版验证顺序：已有追踪与事件数据，事件型 VAEP 基线，再加入空间信息，然后才训练候选传球的成功率与价值，最后才考虑视频感知带来的位置误差。
