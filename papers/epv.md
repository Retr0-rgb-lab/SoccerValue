## 它解决什么

预期控球价值（EPV）估计当前局面下，哪一方更可能打进下一球。论文不把这个值做成单一黑盒，而是按传球、带球、射门拆开，再把传球和带球各自拆成成功与失败。传球可以落到场上任意位置，所以与传球相关的量是整张图；带球和射门用浅层网络估计单个值。

候选传球的期望可以写成成功概率乘成功后的价值，加上失败概率乘失败后的价值。成功或失败之后的价值仍是对后续局面的期望，而不是假设未来只有一个确定结果。

| 子任务 | 方法 | 输出 |
| --- | --- | --- |
| 传球成功概率 | SoccerMap 多尺度全卷积网络 | 全场各目标点的成功概率 |
| 成功传球后的价值 | 单独的 SoccerMap 网络 | 全场成功条件下的价值图 |
| 失败传球后的价值 | 单独的 SoccerMap 网络 | 全场失败条件下的价值图 |
| 传球目标选择概率 | SoccerMap，再对全场做 softmax | 历史行为下更可能传到哪里 |
| 带球成功概率及成功／失败价值 | 浅层全连接网络 | 相应概率和价值 |
| 射门价值 | 基于空间与上下文特征的浅层网络 | 射门预期收益 |
| 传球／带球／射门的选择概率 | 浅层网络 | 三类动作的选择分布 |

## 在本题中的位置

这是从事后评价走到事前比较的桥梁。比赛状态在这里汇合：空间站位加上近期动作，然后生成候选传球，再分别估计成功概率、成功后价值和失败后价值。加入全体球员位置、并对未执行动作打分之后，得到的是扩展后的空间动作价值，沿用的是“进球概率相对失球概率”这一价值思想，模型本身不再是只看最近三个动作的原版 VAEP。
